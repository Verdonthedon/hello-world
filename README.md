# The God Mode Retreat — Landing Page

A single-page landing site for a fictional 5-day transformational retreat in
Bali, recreated as an independent, inspiration-only build (no assets or code
copied from the original).

## What it is

A high-conversion retreat landing page that leans on the patterns that make
these pages work:

- An emotional hero with clear value proposition and date/location
- Scarcity ("12 souls · 1 seat remaining")
- A "what's included" grid
- A day-in-the-life timeline
- "Who it's for / not for" qualification
- Testimonials, host credibility, and an FAQ that handles objections
- A repeated, single call-to-action (application form)

## Stack

Plain HTML, CSS, and vanilla JavaScript — no build step, no dependencies.

| File | Purpose |
|------|---------|
| `index.html` | Page structure and copy |
| `styles.css` | Cosmic dark theme, layout, animations |
| `script.js` | Scroll reveals, sticky nav, application form |

## Run it

Open `index.html` directly, or serve the folder:

```sh
python3 -m http.server 8000
# then visit http://localhost:8000
```
